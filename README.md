# Otevřená galerie

Virtuální 3D výstavní sál (Three.js). Návštěvník si vybere postavu, prochází sálem, prohlíží obrazy a může pověsit vlastní obraz na zeď.

- `index.html` – celá aplikace v jednom souboru
- `netlify.toml` – nastavení pro Netlify (publikuje kořen repozitáře, bez buildu)

Na vlastním webu běží galerie v místním režimu: obrazy, které návštěvník pověsí, se ukládají jen v jeho prohlížeči.
